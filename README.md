# Python_OS_emulator
***
##  Проект: EmulOS;
## Статус проекта: в процессе разработки;
## Вариант 26.
UltraOS - создаваемый в рамках практической работы эмулятор командной оболочки, похожей на работу в коммандной строке UNIX-подобных ОС.
Приложение реализовано в форме консольного интерфейса (CLI).
Приглашение к вводу содержит имя VFS.
Реализован парсер, который корректно обрабатывает аргументы в кавычках.
Сообщает об ошибке выполнения команд (неизвестная команда, неверные аргументы).
На данном этапе разработки в приложении реализовано три комманды, делящие имя команды и её аргументы по пробелам.
# Команды
## Команды-заглушки
ls - выводит своё имя и аргументы
cd - выводит своё имя и аршумент
## Команды
exit - завершает работу приложения
