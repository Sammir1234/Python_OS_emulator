# О проекте
EmulOS - создаваемый в рамках практической работы эмулятор командной оболочки, похожей на работу в коммандной строке UNIX-подобных ОС.  
Приложение реализовано в форме консольного интерфейса (CLI).  
Приглашение к вводу содержит имя VFS.  
Реализован парсер, который корректно обрабатывает аргументы в кавычках.  
Сообщает об ошибке выполнения команд (неизвестная команда, неверные аргументы).  
На данном этапе разработки в приложении реализовано три комманды, делящие имя команды и её аргументы по пробелам.  
При запуске эмулятора выводятся все заданные параметры.  
К параметрам командной строки добавлены путь к физическому распоолжению VFS и путь к стартовому скрипту.  
Стартовый скрипт для выполнения команд эмулятора: выполняет команды последовательно, ошибочные строки пропускает.  
Сообщает об ошибке во время исполнения стартового скрипта.   
Все операции производятся в памяти.  
Источником VFS является ZIP-архив. Для двоичных данных используется base64.  
Сообщает об ошибке загрузки VFS (файл не найден, неверный формат).  
Созданы 5 скриптов реальной ОС, в которой выполняется эмулятор.   
Создан стартовый скрипт для тестирования всех реализованных на этом и прошлых этапах команд.  
Реализована логика для ls и cd.  
Добавлена команда cat.  
## Новое
Реализованы новые команды uname и uptime.  
Обновлён стартовый скрипт для тестирования новых команд.  
# Команды
* exit - завершает работу приложения  
* ls - выводит содержимое каталогов
* cd - меняет текущую рабочую папку
* cat - выводит содержимое файла
* uname - выводит базовую системную информацию
* uptime - выводит время работы эмулятора
# Скрипты
* run_script - скрипт, предназначенный для тестирования всех реализованных на этом и прошлых этапах команд.
